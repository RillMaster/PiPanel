# 🍓 RaspController

An Android app to manage your Raspberry Pi remotely via SSH.

## 📱 Features

- **Dashboard** — System overview (CPU, RAM, temperature)
- **GPIO Control** — PWM, GPIO Planner, Sensors
- **Docker** — Container management
- **Pi-hole** — Ad blocker control
- **WireGuard** — VPN management and adding clients via QR code
- **Fail2Ban** — Monitoring of banned IPs
- **UFW Firewall** — Firewall rule management
- **Logs Viewer** — Real-time system logs
- **File Manager** — File browsing and management
- **Advanced Monitoring** — CPU, RAM, disk, temperature, network speed

## 🌍 Supported Languages
The app automatically adapts to the system language.

## 🔧 Prerequisites
- Raspberry Pi running Raspberry Pi OS
- SSH enabled on the Pi
- Android 8.0+

## 🚀 Installation

### Option 1 — APK (recommended)
Download the latest version directly from [Releases](../../releases/latest)

### Option 2 — Build from source
1. Clone the repository
2. Open in Android Studio
3. Build and install on your device
